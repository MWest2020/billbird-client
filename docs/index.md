# billbird-client docs

billbird-client is a standalone Python client library, CLI, and MCP server for
reading time-tracking data out of a single [Billbird](https://github.com/MWest2020/Billbird)
instance over its bearer-token REST API. Read-only by design; writes stay on
GitHub slash commands. For install and a quick tour, start at the
[README](../README.md).
